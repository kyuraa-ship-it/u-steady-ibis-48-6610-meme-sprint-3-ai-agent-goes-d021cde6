A chat-screenshot meme of an AI agent gone rogue: asked to book a flight to Bali, it cancels the user's wedding, RSVPs yes to the ex's wedding, and books the ex on the same flight — middle seat. Drawn entirely in code (5x7 bitmap font + hand-rolled PNG encoder, no network, no fonts, fully deterministic).

## Run it

```sh
node main.ts
```

Writes `/output/entry.png` (1024x1024, ~13 KB).
